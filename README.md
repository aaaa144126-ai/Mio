# بوت الفرقة التالتة - تمريض 🩺

بوت تليجرام + موقع مصاحب لتجميع محاضرات وروابط ومذكرات الفرقة التالتة، منظمين كالتالي:

```
ترم (الأول / الثاني) → مادة → محاضرة → مذكرات / فيديوهات / روابط
```

وفيه كمان قسم لطلبات مساعدة الطلاب (طالب يطلب مساعدة في مادة، وأي زميل يقدر يتطوع يساعده).

## المميزات

- **بوت تليجرام للطلاب**: تصفح المحتوى بالكامل بأزرار (Inline Keyboards)، طلب مساعدة، عرض الطلبات المفتوحة والتطوع للمساعدة فيها.
- **أوامر أدمن في البوت**: إضافة مذكرة/فيديو/رابط في خطوات بسيطة بأمر `/addmaterial`، عرض إحصائيات `/stats`، عرض الطلبات `/requests`.
- **موقع مصاحب (Flask)**: تصفح للمحتوى من المتصفح لمن يفضل ذلك + لوحة تحكم أدمن لإضافة الترمات/المواد/المحاضرات ورفع الملفات من المتصفح.
- **تخزين مجاني وأبدي للملفات**: أي ملف بيترفع (من البوت أو من الموقع) بيتبعت لتليجرام ويتخزن بس الـ `file_id` بتاعه في قاعدة البيانات، فمفيش قلق من مساحة التخزين أو من مسح الملفات عند إعادة تشغيل السيرفر (شائع في الاستضافات المجانية).

## هيكل المشروع

```
nursing_bot/
├── app.py                  # تطبيق Flask + تشغيل البوت (Webhook) + الموقع
├── config.py                # قراءة إعدادات البيئة
├── models.py                 # موديلات قاعدة البيانات
├── requirements.txt
├── Procfile                  # لتشغيل المشروع على Render
├── .env.example               # مثال لمتغيرات البيئة
├── telegram_bot/
│   ├── __init__.py            # بناء تطبيق البوت وربط الهاندلرز
│   ├── keyboards.py           # لوحات المفاتيح (الأزرار)
│   ├── handlers_student.py    # هاندلرز الطلاب (تصفح + طلبات مساعدة)
│   └── handlers_admin.py      # هاندلرز الأدمن (إضافة محتوى)
├── templates/                 # صفحات HTML للموقع
└── static/style.css
```

## 1) التجهيز قبل التشغيل

### أ) اعمل بوت تليجرام جديد
1. افتح تليجرام وابحث عن [@BotFather](https://t.me/BotFather)
2. ابعتله `/newbot` واتبع الخطوات (اسم البوت + يوزر نيم ينتهي بـ `bot`)
3. هيديك **توكن** شكله كده: `123456789:AAExampleTokenGoesHere` — احفظه.

### ب) اعرف الآي دي بتاعك على تليجرام
1. ابحث عن [@userinfobot](https://t.me/userinfobot) وابعتله أي رسالة
2. هيديك رقم الآي دي بتاعك — ده اللي هتحطه في `ADMIN_IDS`

### ج) جهّز الكود
```bash
git init
git add .
git commit -m "init"
```
ارفعه على GitHub (repo جديد) عشان تقدر تربطه بالاستضافة.

## 2) التشغيل محليًا (للتجربة قبل النشر)

```bash
python -m venv venv
source venv/bin/activate   # على ويندوز: venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env
# افتح .env واملأ BOT_TOKEN و ADMIN_IDS و ADMIN_PASSWORD

python app.py
```

⚠️ محليًا من غير `BASE_URL`، البوت مش هيستقبل تحديثات (Webhook محتاج رابط عام يوصله). عشان تجرب البوت محليًا استخدم أداة زي [ngrok](https://ngrok.com) عشان تاخد رابط عام مؤقت وتحطه في `BASE_URL`. الموقع (الصفحات والوحة الأدمن) هيشتغل عادي على `http://localhost:5000` من غير الحاجة لـ ngrok.

## 3) النشر على استضافة مجانية دايمة (Render)

1. روح [render.com](https://render.com) واعمل حساب (فيه خطة مجانية).
2. من الداشبورد: **New → Web Service**
3. اربطه بالـ GitHub repo بتاعك.
4. الإعدادات:
   - **Runtime**: Python 3
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `gunicorn app:app --workers 1 --threads 4 --timeout 120`
     (موجودة جاهزة في ملف `Procfile` برضو)
5. من تبويب **Environment**، ضيف المتغيرات دي:
   | المتغير | القيمة |
   |---|---|
   | `BOT_TOKEN` | التوكن من BotFather |
   | `ADMIN_IDS` | آي ديك (وأي أدمنز تانيين، مفصولين بفاصلة) |
   | `BASE_URL` | رابط الخدمة اللي Render هيديهولك، مثال: `https://nursing-bot.onrender.com` |
   | `ADMIN_PASSWORD` | باسورد قوي للوحة تحكم الموقع |
   | `SECRET_KEY` | نص عشوائي طويل |
   | `BOT_TITLE` | اسم البوت اللي هيظهر في الواجهة |
   | `DATABASE_URL` | سيبها `sqlite:///nursing_bot.db` |
6. اضغط **Deploy**. أول ما ينشر، البوت هيظبط الـ Webhook أوتوماتيك على `BASE_URL` (الكود بيعمل ده لوحده عند التشغيل).

> ⚠️ ملاحظة عن SQLite على Render المجاني: القرص فيه مؤقت (Ephemeral) — يعني لو عملت Redeploy جديد ممكن قاعدة البيانات (أسماء الترمات/المواد/المحاضرات وروابط اللينكات) تتصفر، **لكن الملفات نفسها (اللي مخزنة كـ file_id في تليجرام) متأثرتش لو رجعت القاعدة**. لو عايز ثبات كامل للبيانات كمان، أرخص وأسهل حل مجاني: استخدم قاعدة بيانات Postgres مجانية من [Render](https://render.com) أو [Supabase](https://supabase.com) وحط رابطها في `DATABASE_URL` بدل SQLite (تشتغل من غير أي تعديل في الكود لأنها بتستخدم SQLAlchemy).

### بديل: Railway
نفس الخطوات تقريبًا: اربط الـ repo، ضيف نفس متغيرات البيئة، والـ Start Command هو نفسه من `Procfile`.

## 4) استخدام البوت

### للطلاب
- `/start` يفتح القائمة الرئيسية: تصفح المحتوى / طلب مساعدة / الطلبات المفتوحة.

### للأدمن (في تليجرام)
- `/addmaterial` — يبدأ خطوات إضافة مذكرة/فيديو/رابط لمحاضرة (يقدر يختار ترم/مادة/محاضرة موجودة أو يضيف جديد أثناء نفس الخطوات).
- `/requests` — عرض آخر طلبات المساعدة.
- `/stats` — إحصائيات سريعة عن المحتوى.
- `/cancel` — إلغاء أي عملية إضافة شغالة.

فقط الآي ديز الموجودة في `ADMIN_IDS` تقدر تستخدم أوامر الأدمن.

### للأدمن (من الموقع)
- روح على `/admin/login` وسجل دخول بالباسورد اللي حطيته في `ADMIN_PASSWORD`.
- من لوحة التحكم: ضيف ترمات ومواد ومحاضرات، وادخل على أي محاضرة عشان ترفع مذكرة/فيديو (ملف أو رابط).

---

## 5) إضافة أدمن جديد لاحقًا
عدّل قيمة `ADMIN_IDS` في إعدادات البيئة (Render → Environment) وحط كل الآي ديز مفصولة بفاصلة، مثال:
```
ADMIN_IDS=111111111,222222222,333333333
```
وأعمل Redeploy.

## ملاحظات تقنية سريعة
- البوت بيشتغل بنظام **Webhook** (مش Polling) عشان يتوافق مع استضافات الـ Web Service المجانية.
- الملفات بتتخزن في تليجرام نفسه (مجاني وأبدي) — الموقع بيجيب رابط تحميل لحظي لحظة الطلب عن طريق Telegram Bot API.
- لو حابب تضيف قاعدة بيانات Postgres بدل SQLite للثبات الكامل، غيّر بس قيمة `DATABASE_URL` — مفيش تعديل تاني مطلوب في الكود.
